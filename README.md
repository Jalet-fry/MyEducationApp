# MyEducationApp — Интерактивный учебник "Live Code"

**MyEducationApp** — это Android-приложение для изучения Kotlin, Java и Android-разработки. В отличие от статичных учебников, здесь теория подкрепляется мгновенной практикой прямо внутри экрана урока.

## 🚀 Главная фишка: Reactive Execution
Приложение использует кастомный движок **Native Backend**. Это позволяет:
- **Менять параметры UI**: слайдеры, текстовые поля и переключатели мгновенно меняют входные данные для кода.
- **Видеть результат в реальном времени**: код «выполняется» в виртуальной консоли приложения.
- **Чувствовать асинхронность**: в уроках по Coroutines и Flows лог выводится с задержками (delay), имитируя реальную работу потоков.

## 🏗 Архитектура
- **Движок уроков**: Каждый урок — это объект `LessonBackend`, реализующий логику на чистом Kotlin.
- **Master Lessons**: Мы группируем мелкие темы (например, типы данных или циклы) в один большой интерактивный модуль, чтобы избежать фрагментации.
- **UI**: Написан полностью на **Jetpack Compose**.
- **Syntax Highlighting**: Собственный парсер для подсветки кода.
