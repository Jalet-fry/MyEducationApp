# Структура проекта MyEducationApp

Данный проект представляет собой интерактивное обучающее приложение для Android, ориентированное на изучение программирования (Kotlin, Java, Android).

## Общая архитектура
Приложение построено на **Jetpack Compose** с использованием навигации (`Compose Navigation`).
Контент уроков не статичен, а генерируется через так называемые "Бэкенды" (`LessonBackend`), что позволяет не только отображать текст и код, но и выполнять логику уроков интерактивно с параметрами.

## Корневая папка проекта
* `build.gradle.kts`, `settings.gradle.kts` — конфигурация сборки Gradle.
* `PROJECT_STRUCTURE.md` — этот файл, описание проекта.
* `NATIVE_BACKEND_PLAN.md` — план реализации нативных бэкендов.
* `downloader.py`, `generate_lessons.py`, `script_download_php.py` — Python скрипты для автоматизации загрузки и обработки контента (вероятно, с сайта Metanit).
* `metanit_*.json` — JSON файлы с данными уроков, полученные скриптами.

## Модуль `:app`

### Пакет `vitos.example.myeducationapp`
* `MainActivity.kt` — точка входа. Настраивает навигацию и инициализирует репозиторий.
* `SyntaxHighlighter.kt` — компонент для подсветки синтаксиса кода в уроках.

### Пакет `.data` (Модели данных)
* `Course.kt` — модель курса (ID, заголовок, цвет).
* `Lesson.kt` — модель урока, содержащая секции (текст, код) и параметры.
* `LessonsRepository.kt` — связующее звено между UI и реестром бэкендов. Предоставляет данные об уроках.

### Пакет `.logic` (Ядро и контент)
* `LessonBackend.kt` — **ключевой интерфейс**. Определяет структуру урока:
    * `sections` — контент (текст/код).
    * `parameters` — интерактивные переменные, которые пользователь может менять.
    * `execute()` — функция, выполняющая "код" урока и возвращающая результат.
* `LessonRegistry` — синглтон, где регистрируются все уроки при запуске.
* Пакеты `android/`, `java/`, `kotlin/` — содержат реализации уроков, разбитые по темам.
    * Например, `kotlin/basics/Basics.kt` регистрирует базовые уроки по Kotlin.

### Пакет `.ui` (Интерфейс)
* `components/` — общие UI элементы:
    * `CodeSection.kt` — отображение блока кода с подсветкой.
    * `CourseCard.kt` — карточка курса в списке выбора.
    * `ParameterEditor.kt` — интерфейс для изменения параметров урока пользователем.
* `lessons/`
    * `LessonBackends.kt` — содержит `registerAllLessonBackends()`, которая вызывает регистрацию всех тем во всех курсах.
* `screens/` — экраны приложения:
    * `CourseSelectionScreen.kt` — выбор курса (Kotlin/Java/Android).
    * `LessonListScreen.kt` — список глав и уроков выбранного курса.
    * `LessonDetailScreen.kt` — детальное отображение урока: контент, редактор параметров и консоль вывода результата.
* `theme/` — настройки темы (цвета, шрифты).

## Как это работает (Workflow)
1. При запуске `MainActivity` вызывает `registerAllLessonBackends()`.
2. Все уроки регистрируются в `LessonRegistry`.
3. Пользователь выбирает курс -> `LessonListScreen` запрашивает список через `LessonsRepository`.
4. При переходе в урок `LessonDetailScreen` получает `LessonBackend` по ID.
5. Пользователь может менять `parameters` в UI, что приводит к пересчету `execute()` и обновлению "консоли" внизу экрана.
